# 反滥用、安全与治理设计（设计稿）

> 状态：尚未实现。邀请制和端到端加密会降低公开垃圾信息，但不会自动消除骚扰、恶意文件、被盗设备、服务资源滥用或群管理员滥权。

## 原则

- 私聊内容默认只在参与设备解密；服务端不做常规内容扫描、关键词过滤或行为画像。
- 用户优先拥有本地阻止、退出、静音、隐藏敏感媒体和设备核验能力。
- 群管理员只管理成员资格和邀请能力，不能读取内容、伪造成员、导出密钥或绕过成员变更。
- 举报必须由用户主动选择要提交的内容与元数据，且清楚说明提交后不再是端到端私密的范围。
- 服务资源防护按协议/连接/网络层实施，不以收集聊天内容为代价。

## 威胁与控制

| 风险 | 客户端控制 | 服务端/运维控制 | 不承诺 |
| --- | --- | --- | --- |
| 陌生人骚扰 | 邀请确认、阻止、静音、退出群 | 邀请过期/限额、连接限流 | 阻止已获邀请成员截图/转发 |
| 垃圾消息/资源耗尽 | 本地折叠、文件大小提示 | 令牌桶、大小限制、边缘 DDoS 防护 | 只靠客户端阻止网络洪泛 |
| 恶意文件/链接 | 默认不预览、显示类型/大小、用户确认打开 | 密文对象配额/过期/下载令牌 | 服务端扫描 E2EE 文件 |
| 身份仿冒 | 设备安全码、目录透明性、身份变化警告 | 目录 proof、撤销、KeyPackage 生命周期 | 替用户判断现实身份 |
| 管理员滥权 | 可见成员变更、安全事件、退出/迁移 | MLS Commit 可验证、管理操作审计 | 收回成员已保存的明文 |
| 被盗设备 | 本地锁定、吊销设备、会话轮换 | 停止令牌/投递、目录撤销 | 远程擦除已复制内容 |

## 邀请与成员治理

- 邀请默认一次性或短期有效，绑定目标公开 credential 或需要接收方明确确认；不使用可枚举永久邀请码。
- 管理员可设置有效期、最大使用次数和是否需现有成员确认，但这些规则写入经过认证的群策略，不能只依赖服务端数据库布尔值。
- 成员移除、管理员权限变化、群解散均通过 MLS 成员变更和新的 epoch 生效；客户端显示安全事件。
- 群角色最小化为成员、管理员和可选邀请协管；不提供“隐形管理员”或能静默导出内容的角色。
- 管理员 token 仅是过渡原型凭证。正式版本使用经 MLS/目录验证的角色授权与设备签名。

## 本地保护功能

- 阻止设备/联系人：客户端不再渲染其新内容、不发已读/输入状态、不自动接受邀请；阻止列表仅本地加密保存。
- 退出群：停止接收新内容并请求成员移除；界面说明退出无法删除已接收历史。
- 敏感媒体：默认不自动下载/播放；文件与外链要显示来源设备、类型、大小和过期状态。
- 安全中心：集中展示设备密钥变化、目录异常、群成员变更、恢复、端点/更新签名异常，并提供可操作建议。
- 保护性通知：锁屏通知默认不显示私聊正文、文件名或群名；用户可按会话选择更严格设置。

## 用户主动举报

举报流程只在用户选择后发生：

1. 用户在本机选择具体消息、文件描述符、成员事件或安全异常。
2. 客户端显示将提交的最小材料、接收方、保留期与“这部分内容将离开 E2EE 会话”提示。
3. 客户端把用户选中的内容、必要的验证上下文和用户说明加密给独立举报处理公钥；不上传整个会话、私钥、恢复材料或通讯录。
4. 服务端将举报队列与聊天投递、公告和目录系统隔离，权限/日志/保留期独立。
5. 处理结果只影响服务资源访问、公告发布或公开目录资格；不能让运维人员解密未被用户选择提交的聊天内容。

对自托管部署，举报端点可由管理员关闭；客户端需如实显示其不可用，而不是把报告发送到未知第三方。

## 网络与服务防护

- 在边缘层实施 IP/ASN/连接速率、TLS/协议异常、对象存储配额和 WebSocket 并发控制；保留期短，访问受限。
- 在中继层实施 schema、认证、每连接消息速率、历史分页和广播背压；不解析密文。
- 匿名/代理用户可能被误伤，因此限流应优先使用短期连接/能力令牌和渐进式挑战，而不是永久网络黑名单。
- 对公开公告发布后台使用更严格的设备确认、审批、签名和速率策略；公告服务永不获得私聊解密能力。

## 透明度与申诉

- 公开说明服务可执行的动作：拒绝连接、限流、撤销邀请/发布资格、下架公开公告、冻结服务资源。
- 对私聊内容不做服务器端常规审查，因此不能承诺检测所有违法、有害或不当内容。
- 任何影响公开身份/公告发布资格的长期处置应有最小证据、期限、审计和申诉路径。
- 统计透明度只发布聚合数量和政策变化，不发布用户、群、举报正文或可关联时间线。

## 验收门槛

- 阻止、退出、成员移除、邀请过期、限流和设备吊销均具备端到端测试。
- 举报 UI 必须在发送前显示精确提交范围；测试证明不会附带整个会话或敏感密钥。
- 服务端日志扫描证明反滥用路径不接收未选择的聊天明文。
- 群管理员无法通过旧 token、服务端成员表或设备 ID 绕过 MLS 成员变更。
- 发布隐私/安全文案准确区分本地保护、服务资源治理与内容审核边界。
