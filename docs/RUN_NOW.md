# 先跑通（同 Wi‑Fi，不填公网）

目标：电脑 + 手机马上能聊，**先不配公网**。

## 1. 电脑启动服务器

```bat
cd C:\Users\holyx\Downloads\secure-invite-chat\server
python server.py
```

终端会打印类似：

```text
手机请连同一 Wi-Fi，在 App 里填下面地址之一：
  → ws://192.168.124.4:8765
```

**记下这个地址。**

## 2. 电脑打开客户端

```bat
cd C:\Users\holyx\Downloads\secure-invite-chat
npm run dev
```

浏览器打开提示的地址。应显示「已连接」。  
首页若出现「手机请填这个地址」，点一下复制。

## 3. 手机

1. 连 **和电脑相同的 Wi‑Fi**（不要用流量）  
2. 打开 App  
3. 地址填：`ws://192.168.x.x:8765`（与电脑终端一致）  
4. 点 **连接** → 显示已连接  
5. 电脑 **创建群** → 复制邀请码  
6. 手机 **输入邀请码加入** → 互发文字/文件  

## 注意

| 不要 | 要 |
|------|-----|
| 手机用 4G/5G 填 192.168 | 同一 Wi‑Fi |
| 手机填 127.0.0.1 | 填电脑局域网 IP |
| 单机调试开着 | 关闭，连服务器 |

公网 / 手机流量：程序稳定后再做。
