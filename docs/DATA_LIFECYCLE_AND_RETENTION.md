# 数据生命周期、保留与删除设计

> 状态：尚未实现。本文定义最小化保留目标，不构成法律意见。实际保留期、地域、备份和法定例外必须由部署者依据适用法律、合同和风险评估配置并向用户披露。

## 基本原则

- 默认少收集、少保存、短期保留、按域隔离；不得为了将来可能有用而保存完整可关联记录。
- 内容、密钥、身份目录、文件、公告、推送、可观测性和反滥用数据分别管理，不能用一个统一用户档案关联。
- 删除的语义分层说明：停止访问、停止投递、服务端删除、本地删除、备份过期、他人副本无法收回。
- 服务端永不持有聊天明文、私钥、MLS 私密 state 或 Recovery Secret；因此不能提供“服务端找回聊天内容”。

## 数据清单

| 数据域 | 最小内容 | 保存位置 | 默认生命周期 |
| --- | --- | --- | --- |
| 设备安全状态 | 私钥句柄、加密 MLS state、阻止列表、验证历史 | 用户设备安全存储/加密数据库 | 用户删除/设备吊销时本地清除 |
| 中继投递 | 密文消息、最小投递序号、短期队列状态 | 中继密文库 | 到期/确认策略后删除 |
| 文件对象 | 加密 manifest、加密分块、对象保留时间 | 对象存储 | 到期、撤回或配额清理 |
| 目录 | 公开 credential、设备状态、KeyPackage 引用、透明性 proof | 目录/不可变日志 | 公开版本历史与撤销所需期间 |
| 公告 | 已签名公开内容与撤回记录 | 公告服务/CDN/本地缓存 | 公告有效期与透明性需要期间 |
| 推送 | 不透明唤醒 token 与短期消息提示 | 推送平台注册/服务端 | 失效、设备吊销或用户关闭时删除 |
| 运维 | 聚合健康指标与最小安全事件 | 独立遥测系统 | 最短运营需要期 |
| 举报 | 用户主动选择的证据与处置记录 | 独立受限系统 | 公开政策中的有限期 |

## 服务器端删除语义

### 消息

- 投递服务的持久化密文是离线投递缓冲，不应成为无限期云端聊天归档。
- 每个会话配置最大未确认保留期、最大消息数/字节数与清理策略；超限时客户端得到明确同步/丢失提示，服务端不得悄悄无限保存。
- 删除消息对服务端只意味着删除待投递/缓存密文；已接收设备可能仍保留明文或备份。
- 删除/过期作业记录只保留聚合结果或不可关联作业 ID，不记录消息正文、群名或完整设备集合。

### 文件

- 上传未完成对象使用短 TTL；完成对象受 descriptor 的 expiresAt、配额和撤回策略约束。
- 删除按主对象、分块、CDN 缓存、索引、预签名授权和备份队列分步骤执行，并保留可验证删除状态。
- 服务端不能验证所有用户副本已被删除，也不能撤销已被成员导出的 fileKey/明文。

### 设备与目录

- 吊销设备后立即停止投递、KeyPackage 发放、文件令牌和推送；公开撤销记录保留以防旧设备重新被信任。
- 删除账户时删除活跃投递索引、推送 token、未完成文件和可选备份引用；目录中为透明性而保留的历史条目应最小化/去标识化并明确说明。
- 公开 credential 不能直接绑定手机号/邮箱；用户主动公开的别名与目录记录的可见性由独立策略控制。

## 客户端本地删除

- 删除会话：清除该会话的加密数据库记录、缓存附件、下载进度、缩略图和相关短期令牌；安全存储中撤销对该会话状态的访问。
- 删除设备/重装：清除私钥句柄引用、加密状态和推送注册；安全硬件无法保证物理介质立即覆写时，产品说明平台限制。
- 清除缓存：只删除可再获取的密文/公开公告缓存，不删除用户尚未备份的恢复材料，除非用户明确确认。
- 本地删除前显示范围与不可逆后果；禁止把“退出群”或“删除 UI”误称为已从所有成员设备删除。

## 备份与灾备

- 聊天内容和 MLS state 不进入服务端明文备份。若提供加密恢复 bundle，其密钥仅由用户 Recovery Secret 控制。
- 服务端数据库/对象存储备份使用独立加密、最小访问、版本到期和删除队列；备份保留期及不可即时删除的窗口须公开。
- 恢复演练使用合成数据，不能把生产密文、设备 credential 或推送 token复制到低权限环境。
- 灾备恢复后必须重新验证目录 checkpoint、发布签名、密钥状态与删除队列，避免从过期备份重新启用已吊销设备。

## 用户可见控制

设置中提供：

- 每个会话的本地保留和自动清除策略。
- 文件自动下载、缓存大小、公告缓存与离线数据清除。
- 推送开关、锁屏内容粒度和诊断发送同意。
- 设备/恢复/备份状态与“删除将影响什么”的预览。
- 指向部署者数据保留、地域、备份、举报和法律例外政策的版本化说明。

所有默认值由部署配置签名并在客户端展示版本；服务器不得对单个用户悄悄延长保留期。

## 验收门槛

- 集成测试验证到期消息/文件、设备吊销、账户删除、推送失效、缓存清除和备份过期按预期运行。
- 数据库存储、对象路径、日志、备份和监控扫描证明未含聊天明文、私钥、Recovery Secret 或完整可关联身份。
- 删除状态 UI 与实际任务状态一致；失败/延迟可见且可重试，不显示虚假的“已从所有设备删除”。
- 部署者为每类数据指定所有者、用途、访问角色、默认期限、备份窗口、删除机制和用户通知文本。
