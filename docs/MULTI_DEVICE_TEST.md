# 双端联调清单

测试顺序（按产品要求）：

1. **阶段 A：桌面端 ↔ 手机端**
2. **阶段 B：手机端 ↔ 手机端**

两端都必须 **关闭「本地调试」**，连同一台中继。

---

## 公共准备（电脑）

```bat
cd C:\Users\holyx\Downloads\secure-invite-chat\server
pip install -r requirements.txt
python server.py
```

应看到监听 `0.0.0.0:8765`。

查局域网 IP（PowerShell / CMD）：

```bat
ipconfig
```

记下 IPv4，例如 `192.168.1.8`。

Windows 防火墙如拦截，放行入站 TCP **8765**。

---

## 阶段 A · 桌面 ↔ 手机

| 角色 | 设备 | 操作 |
|------|------|------|
| 中继 | 电脑 | `python server.py` 保持运行 |
| 管理端 | 电脑浏览器 | `npm run dev` → 关本地调试 → `ws://127.0.0.1:8765` → **创建群** → 复制邀请串 |
| 成员 | 手机 APK | 关本地调试 → `ws://192.168.x.x:8765` → **加入群** 粘贴 SIC1… |

### 验收项

- [ ] 桌面顶栏：中继在线（非「本地调试」）
- [ ] 手机顶栏：中继在线
- [ ] 手机进群成功
- [ ] 桌面 → 手机：文字
- [ ] 手机 → 桌面：文字
- [ ] 双向：链接卡片可点
- [ ] 双向：图片预览 / 文件保存
- [ ] 双方「安全码」一致

---

## 阶段 B · 手机 ↔ 手机

| 角色 | 设备 | 操作 |
|------|------|------|
| 中继 | 电脑 | 继续跑 `server.py`（可关掉桌面网页） |
| 管理端 | 手机 A | 关本地调试 → 同一 `ws://电脑IP:8765` → **创建群** → 分享邀请串 |
| 成员 | 手机 B | 同样 WS → **加入群** 粘贴邀请串 |

### 验收项

- [ ] 两台手机均中继在线
- [ ] B 成功进群
- [ ] A ↔ B 文字 / 链接 / 图片 / 文件
- [ ] 安全码一致

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 一直「连接中 / 已断开」 | 中继未开、IP 错、防火墙、不在同一 Wi‑Fi |
| 手机填了 127.0.0.1 | 改成电脑局域网 IP |
| 加入失败 | 邀请串不完整；或仍开着本地调试 |
| 能进群不能收消息 | 双方是否同一 group；重开 App 触发 resume |
| 本地调试开着 | 设置里关闭，点保存 |
