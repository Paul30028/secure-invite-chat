# 安全状态与隐私体验规范

> 状态：尚未完整实现。本规范定义客户端如何诚实呈现安全能力、限制和异常；禁止用绿色盾牌或模糊“已加密”文案掩盖旧协议、目录异常或功能降级。

## 设计原则

- 安全状态必须可操作：每个警告都给出下一步，而不仅是一句技术错误。
- 仅展示已实际验证的属性。传输 TLS、端到端消息、已验证设备、MLS 保护、媒体 E2EE、隐私代理是不同标签。
- 高风险异常优先显示、不可被普通聊天淹没；用户可稍后处理，但不能无限静默隐藏。
- 避免迫使用户理解密码学细节；使用明确后果和可信渠道核验。
- 无法实现的能力不显示为关闭的“高级开关”，而应说明当前客户端/会话不支持。

## 会话安全状态

| 状态 | 显示文案 | 含义 | 用户动作 |
| --- | --- | --- | --- |
| 旧会话 | 旧版加密会话 | 共享群密钥/旧状态，缺少 MLS 成员变更保护 | 迁移到新会话 |
| 建立中 | 正在验证会话 | 正在认证设备或同步 MLS/目录状态 | 等待；失败后重试 |
| 已保护 | 端到端保护已启用 | 消息使用当前受支持协议加密 | 查看成员与安全码 |
| 已验证 | 设备身份已验证 | 目录与安全码/用户确认满足要求 | 可查看验证详情 |
| 目录未刷新 | 使用已验证缓存 | 网络离线或目录暂不可用；不接受新密钥 | 恢复网络后刷新 |
| 身份变化 | 设备身份需要确认 | 已知设备 credential 改变、增加或恢复 | 线下核验、批准或吊销 |
| 目录异常 | 无法验证身份目录 | proof、checkpoint 或一致性验证失败 | 停止敏感操作、检查网络/公告 |
| 已移除 | 已不再是成员 | 当前设备被移除或会话结束 | 删除本地会话或联系管理员 |

“已保护”不能单独代表“对方身份已验证”；“已验证”不能代表“隐藏 IP”或“防止截图”。

## 顶层安全中心

设置中提供固定入口，按风险排序展示：

1. 需要立即处理：目录异常、发布签名错误、设备身份变化、恢复/配对请求、被移除。
2. 建议处理：未配置恢复、旧会话待迁移、未核验安全码、即将过期的设备/邀请。
3. 信息：当前版本、已验证端点、公告发布者、网络模式、上次目录刷新。
4. 历史：成员变更、设备添加/吊销、恢复、端点切换和更新验证；历史只在本机加密保存。

每个条目显示发生时间、受影响会话/设备、已验证证据摘要和操作按钮。不得显示私钥、完整 credential、聊天正文或恢复材料。

## 安全码与身份核验

- 安全码基于双方当前公开身份/设备集合和会话上下文，以短数字/词组和 QR 两种形式展示。
- 扫描或对比成功后，本机保存验证状态；设备集合改变时使相关验证过期，并明确提示原因。
- “我已核验”是用户声明，不是密码学证明；UI 必须区分“目录自动验证”与“用户线下比对”。
- 不建议用户把安全码发送到同一个待验证聊天中；提示使用面对面、电话或另一可信渠道。
- 对群聊显示成员设备摘要，而不是夸大为“所有人都已验证”；允许用户查看缺少验证的设备。

## 关键流程 UX

### 建群/入群

1. 显示会话类型、邀请来源、有效期和目标端点信任状态。
2. 入群前提示：邀请码不是消息内容密钥；不要在公开场所分享。
3. 加入完成后显示“正在建立受保护会话”，等待 MLS/目录验证，不提前展示完全安全的绿标。
4. 旧协议邀请在 UI 中标为兼容/迁移前，不能与正式会话外观相同。

### 设备配对与恢复

1. 新设备明确显示“这会授权一台新设备”，附设备名、平台和短过期时间。
2. 旧设备端要求用户主动确认安全码；无确认时自动过期。
3. 恢复页面先说明恢复不会取回旧私钥或保证全部历史；避免用户误以为“密码忘了也能恢复”。
4. 成功/失败都向安全中心写入本地事件；异常恢复可一键吊销。

### 发送文件与链接

1. 文件发送前显示大小、类型、加密状态和保留期；大文件/未验证会话给出明确阻断原因。
2. 接收端默认不下载敏感内容；打开前展示来源设备、文件名、类型、大小与完整性状态。
3. 链接只显示文本与目标域名；任何预览功能都需会话级/全局显式开关和隐私说明。
4. 校验失败文件不可“仍然打开”，只能删除或导出受限诊断。

### 通话

1. 通话前显示网络模式：直连可能暴露对端 IP，隐私优先模式使用中继。
2. 只有媒体帧 E2EE、身份验证和当前成员版本均满足时，显示“私密通话已验证”。
3. 不支持帧 E2EE 的设备显示明确原因，不提供静默“继续”降级按钮。
4. 通话中持续显示麦克风、摄像头、屏幕共享、网络模式和安全状态；成员变化/密钥轮换时可见。

## 通知与锁屏

- 默认只显示“有新消息”或用户选择的最小摘要；不显示正文、群名、文件名或安全码。
- 安全告警可在锁屏显示“需要处理的安全事件”，但不泄露受影响联系人/群。
- 公告通知标记为公开内容，与私聊通知使用不同图标/语气。
- 用户能按全局、会话和设备锁定状态控制通知粒度。

## 可访问性与本地化

- 不只依赖颜色：每个安全等级同时有文字、图标、屏幕阅读器标签和键盘可达操作。
- 不以“红色=危险”制造恐慌；文案说明可能影响、可信操作和非技术解释。
- 安全码、时间、设备名、错误原因和隐私说明必须可本地化，且翻译审查不改变安全语义。
- 低带宽/无障碍模式可隐藏装饰性动画，但不能隐藏安全状态或确认步骤。

## 验收门槛

- 可用性测试中，用户能区分“消息被加密”“设备已验证”“旧会话”和“目录异常”至少四种状态。
- 每个异常状态有不超过两步的安全行动或明确的等待/支持说明。
- 截图/自动化 UI 测试验证：身份变化、目录错误、旧协议、媒体降级、恢复和文件完整性失败都不会显示错误绿标。
- 文案审查确认没有“完全匿名”“无法监控”“永远安全”或等价的绝对承诺。
