# 真机直连验收清单

目标：**桌面创建群 → 手机填邀请码 → 文字/文件互通**，并验收 **成员列表 / 踢人**。

## 准备

### 电脑

```bat
cd C:\Users\holyx\Downloads\secure-invite-chat\server
python server.py
```

另开终端：

```bat
cd C:\Users\holyx\Downloads\secure-invite-chat
npm run dev
```

浏览器打开终端提示的地址（如 `http://127.0.0.1:1420`）。

查局域网 IP：`ipconfig` → IPv4（如 `192.168.1.8`）。  
防火墙放行 **TCP 8765**。

### 手机

- 与电脑 **同一 Wi‑Fi**
- 安装最新 APK（`npm run build:android`）或访问电脑 `http://电脑IP:1420`（开发）
- **设置 → 连接地址**：`ws://192.168.1.8:8765`（改成你的 IP）→ 保存并连接  
- 顶栏显示 **已连接**

## 验收 A · 邀请与聊天

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 桌面：创建群（群名 + 昵称） | 弹出 **本群邀请码** |
| 2 | 桌面：复制邀请码 | 剪贴板为 `SIC1.…` 整段 |
| 3 | 手机：输入邀请码 + 昵称 → 加入 | 进入同名群，可看历史（若有） |
| 4 | 桌面发文字 | 手机收到并可解密 |
| 5 | 手机发文字 | 桌面收到 |
| 6 | 任一方发 **链接** | 对方可点开链接卡片 |
| 7 | 任一方发 **图片/文件**（≤4MB） | 对方可预览/保存 |
| 8 | 双方点 **安全码** | 内容一致 |

## 验收 B · 成员列表与踢人

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 任一方点 **成员** | 列表含桌面管理端 + 手机成员 |
| 2 | 在线状态 | 两端在线时显示绿点「在线」 |
| 3 | 管理端（桌面）对手机点 **踢出** | 确认后手机提示被移出，退回无该群 |
| 4 | 手机再发消息 | 失败 / 已不在群（`not_a_member`） |
| 5 | 桌面成员列表 | 只剩管理员 |
| 6 | 手机用 **新邀请码** 再加入 | 可重新进群 |

注意：踢人只取消服务器成员资格；当前 **无前向保密**，旧密钥设备理论上仍可能解历史密文。

## 手机开流量（4G/5G）

局域网 `192.168.x.x` **不可用**。需要：

1. 服务器有**公网 IP**（或内网穿透），防火墙放行 **8765**  
2. 手机设置连接：`ws://公网IP:8765`  
3. 或管理端邀请码内嵌：`SIC1.…|ws://公网IP:8765`（加入时自动连）  
4. 开关飞行模式后 App 会 **自动重连**（online / 回前台）

## 密钥与昵称

| 项 | 规则 |
|----|------|
| 群密钥材料 | 建群时 **CSPRNG 随机**，每群不同 |
| 入群码 | 可轮换；轮换 **不改** 群密钥 |
| 昵称 | 同群 **不能重名**（不区分大小写） |

## 常见问题

| 现象 | 处理 |
|------|------|
| 手机连不上 | IP 是否正确；Wi‑Fi 或公网；防火墙 8765 |
| 开流量后掉线 | 改公网地址；杀后台后重开；看是否自动重连 |
| 邀请码无效 | 完整 SIC1；同一台 server |
| 昵称被占用 | 换一个不同昵称 |
| 成员列表空 | 刷新；重启已更新的 `server.py` |
